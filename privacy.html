MCORG プライバシーポリシー

Privacy Policy ／ 制定日：2026年10月30日（Effective: October 30, 2026）

1. 対象

このポリシーは、Windows デスクトップアプリ「MCORG」（以下「本アプリ」）が、Google アカウントおよび Microsoft アカウントのデータをどのように扱うかを説明するものです。本アプリは開発者が個人で使うために作成したものです。

This policy explains how the Windows desktop app "MCORG" (the "App") handles data from Google and Microsoft accounts. The App is made for the developer's personal use.

2. アクセスするデータ

本アプリは、ユーザーがログインして許可した範囲で、次のデータにアクセスします。

  • メール（一覧・本文・添付ファイル・ラベル／フォルダ）の閲覧、送信、整理
  • メールの仕分けルール（Gmail のフィルタ、Outlook の受信トレイのルール）の閲覧・作成・変更
  • カレンダー（予定表）と予定の閲覧・作成・変更・削除
  • アカウント名とメールアドレス（画面表示のため）

With the user's permission, the App reads, sends and organizes email; reads and edits mail filters/rules; reads and edits calendars and events; and reads the account name and address for display.

3. データの使い方と保存

  • メールと予定のデータは Google・Microsoft のサーバーに置いたまま、画面に表示するために必要な分だけを取得します。
  • 取得したデータは、ユーザーの PC 上で表示するためだけに使い、開発者や第三者のサーバーには送信しません。
  • ログイン状態を保つための認証情報（トークン）は、ユーザーの PC に Windows の暗号化機能（DPAPI）で暗号化して保存します。パスワードは保存しません。
  • データを広告、販売、AI の学習などに使うことはありません。

Data stays on Google's and Microsoft's servers; the App fetches only what it displays, uses it only on the user's PC, and never sends it to the developer or any third party. Sign-in tokens are stored on the user's PC encrypted with Windows DPAPI; passwords are never stored. Data is never used for advertising, sold, or used to train AI models.

4. Google のデータについて（Limited Use）

MCORG's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use（限定使用）の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

5. アクセスの取り消し

本アプリのアクセス権は、いつでも次のページから取り消せます。取り消すと、本アプリはそのアカウントのデータにアクセスできなくなります。

  • Google：https://myaccount.google.com/permissions
  • Microsoft：https://account.live.com/consent/Manage

本アプリの設定画面からアカウントを削除すると、PC に保存された認証情報も削除されます。

You can revoke access at any time from the pages above. Removing an account in the App also deletes its stored tokens from the PC.

6. お問い合わせ

このポリシーに関するお問い合わせは、本アプリの GitHub リポジトリの Issues からお願いします。

For questions about this policy, please open an issue in the App's GitHub repository.
